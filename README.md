# Kubernetes Networking with Cilium and eBPF

Laboratory environment developed as part of the Master's Thesis:

"Análisis e implementación del networking en Kubernetes mediante Cilium y eBPF"

The project automates the deployment of a Kubernetes cluster based on RKE2 on Hyper-V using Vagrant and Ansible, and provides a reproducible environment to evaluate networking features implemented by Cilium and eBPF.

## Technologies

- Hyper-V
- Vagrant
- Rocky Linux 9
- RKE2
- Ansible
- Helm
- Cilium
- eBPF
- Hubble
- Prometheus
- Grafana
